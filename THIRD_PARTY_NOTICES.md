# Third-Party Notices

This file lists third-party components distributed with or required by this project, along with their licenses.

If this project ships no third-party code at build time, this file may remain empty. Populate it before the first release that bundles dependencies (compiled binaries, vendored sources, container images, npm `dist`, etc.).

## Format

For each component, list:

- **Name** and **homepage**
- **Version** (or version range, if multiple)
- **License** (SPDX identifier)
- **Source URL** for the copyright notice / full license text
- **Modifications** made by this project, if any

### Example

```text
Component:       example-lib
Homepage:        https://example.com/example-lib
Version:         1.2.3
License:         MIT
Source:          https://github.com/example/example-lib
Modifications:   None.
```
