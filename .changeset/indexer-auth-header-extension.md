An indexer auth header beside the node one. The network screen takes a header
name and value for the indexer; it is applied as a second declarativeNetRequest
rule scoped to the indexer host, covering queries and the subscription
WebSocket handshake alike, re-derived at startup and on every endpoint save.
Reported in the diagnostics report as set or not set, never by value. New
strings are English-only until the catalogues are translated.
