# Getting Support

Different channels for different needs — pick the one that matches your question to get a faster answer.

## I have a question

- **General usage / "how do I…"** — open a thread in [GitHub Discussions](https://github.com/shieldedtech) on the relevant repository.
- **Quick chat** — community channels (linked from the org profile).

## I found a bug

Open an issue using the **Bug report** template on the affected repository. Include:

- What you expected.
- What happened instead.
- Steps to reproduce.
- Version and environment.

## I want to request a feature

Open an issue using the **Feature request** template. Describe the problem first, then the proposed solution. We're more likely to accept a feature framed as a use case than as a spec.

## I found a security vulnerability

**Do not open a public issue.** Follow [SECURITY.md](./SECURITY.md).

## I want to contribute code

Read [CONTRIBUTING.md](./CONTRIBUTING.md) for the process, sign-off requirements, and coding standards.

## Code of conduct concerns

Email legal@shielded.io`. See [CODE_OF_CONDUCT.md](./CODE_OF_CONDUCT.md).
