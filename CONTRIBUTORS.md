# Contributors

Moth began life as an internal wallet at Shielded Technologies and was squashed
into this repository when it was opened up. That squash collapsed several hundred
commits into one, so GitHub's contributor graph credits a single author for work
that was not one person's. This file is the record it replaced.

## Adding yourself

Open a pull request adding your handle. Contributions that are not code — issue
reports that turned into fixes, review that changed a design, documentation —
belong here too; say what it was.
